# Отчет стресс-теста

## Итог

Тест был остановлен по причине: **превышение 95-го перцентиля времени ответа**.

Первые признаки деградации производительности зафиксированы примерно при: **887 VUs**.

Максимальное значение нагрузки, при котором фиксировались плохие ответы: **1517 VUs**.

Максимальное количество активных VUs во время теста: **1633 VUs**.

## Условия остановки теста

Тест автоматически останавливается, если выполняется одно из условий:

- доля HTTP-ошибок превышает 20 %
- доля плохих ответов превышает 20 %
- доля серверных ошибок 5xx превышает 10 %
- 95 % запросов выполняются дольше 3000 мс
- один виртуальный пользователь получил 5 плохих ответов подряд

## Что считается плохим ответом

Плохим ответом считается ситуация, когда:

- статус ответа не равен 200
- сервер вернул ошибку 5xx
- время ответа превысило 3000 мс

## Интерпретация результата

Первые признаки деградации показывают, при какой нагрузке начали появляться отдельные медленные или ошибочные ответы. Максимальное VUs с плохими ответами показывает наибольшую нагрузку, при которой такие ответы были зафиксированы во время выполнения теста.

Если тест остановлен по причине превышения 95-го перцентиля времени ответа, это означает, что основным ограничением системы стало увеличение времени обработки запросов, а не полный отказ сервера.
